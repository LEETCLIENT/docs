# Замена ассетов через ресурспаки

Как делать ресурспак я вас не буду учить, а перечислю доступные ассеты для замены.

## Звуки: assets/leet/sounds

- `waypoint.wav` - звук поставки cloud waypoint

### Module enable/disable:
- `disablelight.wav`
- `disablelong.wav`
- `enablelight.wav`
- `enablelong.wav`

Соответственно звуки от режимов `Toggle sound` - `Light`, `Long`

### Kill sounds:

- `killawp.wav`
- `killprobitie.wav`
- `killtankdestroyed.wav`
- `killtf2crit.wav`

Режимы `Kill sounds` - `AWP`, `Есть пробитие!`, `Танк уничтожен`, `TF2 Crit`

## Картинки: assets/leet/images/world

- `target.png` - TargetESP Image (1062 x 1062, само тело белое, фон прозрачный, [вот пример](/target.png))
