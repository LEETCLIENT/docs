# internal
Библиотека позволяет получить доступ к полям/методам/классам игры

## call(target, method, ...): object
Вызывает метод из `target`
`target` - либо строка (полный package класса) или уже определенный инстанс
`method` - всегда строка (название метода)
## get_field(target, field): object
Возвращает поле из `target`
`target` - либо строка (полный package класса) или уже определенный инстанс
`field` - всегда строка (название поля)
## set_field(target, field, value): boolean
Устанавливает поле в `target`
`target` - либо строка (полный package класса) или уже определенный инстанс
`field` - всегда строка (название поля)
Возвращает `true` если значение успешно изменено
