# remap
Библиотека позволяет получить читабельное название классов/полей/методов
Intermediary -> Yarn

## class(name)
Возвращает название класса типа `Yarn`
## field(class, name)
Возвращает название поля
- class должен быть типа `Intermediary`
## method(class, name)
Возвращает название метода
- class должен быть типа `Intermediary`
