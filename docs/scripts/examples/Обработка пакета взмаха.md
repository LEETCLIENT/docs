# Обработка пакета взмаха
[Packets](https://maven.fabricmc.net/docs/yarn-1.21.8+build.1/net/minecraft/network/packet/PlayPackets.html)
```lua
module.set("swing detector", PLAYER)
events.set_callback(event_send_packet, function(e)
    if e.name == "swing" then
        local hand = internal.call(internal.get_field(e.packet, "hand"), "ordinal")
        client.chat("sent HandSwingC2SPacket, hand: " .. hand)
    end
end)
```
